# Blinkit Power BI Dashboard

## Project Overview
This project is an interactive Power BI dashboard created to analyze Blinkit's sales performance, outlet distribution, item categories, and customer ratings.

The dashboard provides business insights using visual analytics and filtering features.

---

## Dashboard Features
- Total Sales Analysis
- Average Sales & Ratings
- Outlet Establishment Trends
- Item Type Distribution
- Outlet Size Insights
- Outlet Location Analysis
- Interactive Filters

---

## Tools & Technologies
- Power BI
- Excel / CSV
- Data Visualization
- Data Cleaning
- Dashboard Design

---

## Key Insights
- Tier 3 outlets generated the highest sales
- Fruits and Vegetables category contributed maximum revenue
- Supermarket Type1 had the highest total sales
- Average outlet rating remained around 3.9
